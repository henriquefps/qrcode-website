# Architecture

Qrcode is a static single-page app (Vite, React 19, TypeScript) plus a tiny Cloudflare Worker. Everything user-facing runs in the browser; there is no API and no storage of user content.

```
src/
  App.tsx            hash routing (#/create, #/read), Q shortcut, lazy Read / Quick show / About
  components/shell/  AppShell (header), TopNav (Create | Read), AboutDialog
  components/ui/     shadcn radix-vega primitives
  features/create/   content-type inputs, styling panel, live preview, download, presets
  features/read/     camera scanner, image/drop/paste source, result panel
  features/show/     Quick show full-screen overlay
  lib/               pure, unit-tested helpers: qrData builders, parse (Wi-Fi, vCard, otpauth...), preset, decode
  theme/             light/dark/system + palette (localStorage: qrcode.theme, qrcode.palette)
worker/              Worker entry (assets + qrgo.hfps.dev redirect) and routing, tested
```

## Decisions worth knowing

- **Create stays mounted** (hidden) when you switch to Read, so a half-made code survives. Read, Quick show and About are separate chunks loaded on first use.
- **Decoding** goes through one function, `detect(source)` in `src/lib/decode`. It uses the native `BarcodeDetector` when available; otherwise it dynamically imports the `barcode-detector` ponyfill with the `zxing-wasm` binary.
- **PWA** (`vite-plugin-pwa`, generateSW, autoUpdate): the shell, Latin Inter and the main chunks are precached (about 0.9 MiB). The WASM decoder, its chunk and non-Latin font subsets are cached on first use (CacheFirst), so the fallback also works offline once it has run. The plugin writes into `.cloudflare/output/v0/workers/default/assets`, where the Cloudflare plugin puts the client build.
- **Privacy**: no history, no analytics. Clipboard is written only on a user action. Secrets (Wi-Fi password, otpauth secret) are masked by default.
- **Branding** is generated by `scripts/build-icons.mjs` and `scripts/build-maskable.mjs` from `scripts/glyph.svg`; the social image comes from `scripts/social-preview.html`.

# Architecture

Qrcode is a static single-page app (Vite, React 19, TypeScript) plus a tiny Cloudflare Worker. Everything user-facing runs in the browser; there is no API and no storage of user content.

```
src/
  App.tsx            hash routing (#/create, #/read, #/show), Q shortcut, lazy Read / Quick show / About
  components/shell/  AppShell (header), TopNav (Create | Read), AboutDialog
  components/ui/     shadcn radix-vega primitives
  features/create/   content-type inputs, styling panel, live preview, download, presets
  features/read/     camera scanner, image/drop/paste source, result panel
  features/show/     Quick show full-screen overlay (countdown, wake lock, density)
  pwa/               service worker (sw.ts), share target and launchQueue handoff
  lib/               pure, unit-tested helpers: qrData builders, parse (Wi-Fi, vCard, otpauth...), preset, decode
  theme/             light/dark/system + palette (localStorage: qrcode.theme, qrcode.palette)
worker/              Worker entry (assets, qrgo.hfps.dev redirect, /share-target fallback) and routing, tested
e2e/                 Playwright tests against the production build (fixtures generated in global-setup.ts)
```

## Decisions worth knowing

- **Create stays mounted** (hidden) when you switch to Read, so a half-made code survives. Read, Quick show and About are separate chunks loaded on first use.
- **Decoding** goes through one function, `detect(source)` in `src/lib/decode`. It uses the native `BarcodeDetector` when available; otherwise it dynamically imports the `barcode-detector` ponyfill with the `zxing-wasm` binary. A native `detect()` that throws or does not answer in time (2 s for the first call, 4 s after; some Chromium builds on macOS never settle it) switches the page to WASM for good and retries the same image or frame there (`getActiveEngine()` says which engine is in use).
- **PWA** (`vite-plugin-pwa`, injectManifest, autoUpdate): the service worker is `src/pwa/sw.ts` (Workbox). The shell, Latin Inter and the main chunks are precached (about 0.9 MiB). The WASM decoder, its chunk and non-Latin font subsets are cached on first use (CacheFirst); on browsers without a native QR `BarcodeDetector` the WASM pair is also warmed while the app is idle and online (`src/lib/decode/prefetch.ts`), so the first read works offline. The plugin writes into `.cloudflare/output/v0/workers/default/assets`, where the Cloudflare plugin puts the client build.
- **Incoming images**: the manifest's `share_target` POSTs to `/share-target`; the service worker parks the images in a short-lived cache and redirects to `#/read?shared=1`, where `useIncomingFiles` takes them and deletes the cache at once. `file_handlers` (PNG, JPEG, WebP, GIF) arrive through `launchQueue`. Both go to the Read view's image decoder; nothing is kept. Shortcuts: `#/read` and `#/show` (opens Quick show).
- **Quick show** keeps the screen on (Screen Wake Lock), closes itself after 60 s (visible countdown, +60 s, pause; typing restarts it), masks the input by default and drops to error correction L with a density warning for long text (above version 10 at M).
- **Scannability check** (`features/create/useScanCheck.ts`): 400 ms after the last change the styled code is rendered at 400 and 200 px, flattened on white and decoded with `detect()`; `lib/scanCheck` adds WCAG contrast, logo and quiet-zone hints. **Batch** is a lazy chunk; it imports `jszip` on demand, and the `jszip-*.js` chunk is runtime-cached, not precached.
- **Logo icons** (`lib/iconify.ts`, `lib/logoIcons.ts`, `features/create/useIconLogo.ts`): the Logo section lists 15 curated Iconify icons (Lucide, Simple Icons) and searches every open-licensed collection. Choosing one fetches its shapes from `api.iconify.design` (the only cross-origin request; allowed in `connect-src`, cached by the service worker with stale-while-revalidate), colors it and stores it as a data URI in `logoFile`, so the code renders offline afterwards. The preset JSON keeps the icon id, color and the embedded image; the old ids (`wifi`, `web`, ...) map to curated icons.
- **Privacy**: no history, no analytics. Clipboard is written only on a user action. Secrets (Wi-Fi password, otpauth secret) are masked by default.
- **Branding** is generated by `scripts/build-icons.mjs` and `scripts/build-maskable.mjs` from `scripts/glyph.svg`; the social image comes from `scripts/social-preview.html`.
